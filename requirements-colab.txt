# Pinned environment for Block 2 on Colab. These are the exact versions the CPU
# smoke run and the unit tests were proven against. Colab's preinstalled stack
# drifts monthly; installing this file replaces it so a run is repeatable.
#
# torch: the PyPI wheel (CUDA 13.0 build). If torch.cuda.is_available() is
# False after install on your runtime, the driver is older than CUDA 13 needs;
# reinstall with the CUDA 12.6 build of the same version:
#   pip install --force-reinstall torch==2.14.0 --index-url https://download.pytorch.org/whl/cu126
# The run manifest records torch.__version__ and the driver either way.
#
# torchvision / torchaudio: NOT installed, on purpose. Colab preinstalls builds
# tied to its own torch; once torch is replaced they fail to load, and
# transformers surfaces that as a misleading model-import error
# ("operator torchvision::nms does not exist" -> "Could not import module
# 'BloomPreTrainedModel'"). Nothing in this pipeline uses them. Remove them
# before installing:  pip uninstall -y torchvision torchaudio torchao bitsandbytes
# (torchao 0.10 preinstalled on Colab is rejected by peft's LoRA dispatcher probe;
# bitsandbytes is only a hazard if present and broken). scripts/preflight.sh checks
# all four and runs a one-step CPU training before anything is downloaded.
